NOVITA'
La chat può salvare automaticamente alcune informazioni quando il messaggio inizia con:
- "Ricorda: ..."
- "Memorizza: ..."
- "Tieni a mente: ..."
- "Il mio obiettivo è ..."
- "Preferisco ..."
- "Mi piace ..."
- "Ho deciso che ..."

La funzione è attivabile/disattivabile dalla sezione Memoria.
Questa è un'automazione locale basata su regole, NON un modello AI.
I dati restano nel browser/dispositivo e non vengono sincronizzati.
Esportare periodicamente un backup JSON.

IMPORTANTE
Nessuna chiave API è inclusa. Non inserire credenziali o dati sensibili.
Le funzioni di memoria automatica non leggono tutte le conversazioni liberamente:
riconoscono soltanto le formule esplicite elencate sopra.
